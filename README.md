# greeter

Kleiner HTTP-Dienst in Java 21. Übungsprojekt für GitHub Actions.

- Build und Test: `mvn -B verify`
- Ergebnis: `target/greeter.jar`
- Container: `docker build -t greeter .` (nach dem Build)

# Workflows

Es gibt aktuell 3 workflows in diesem Repository. Alle zum testen.
